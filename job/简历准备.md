### uavdetr
#### 1、整体架构讲解：
我这个项目主要解决的是无人机目标检测在复杂场景下性能下降的问题。相比常规自然场景，无人机图像里目标通常更小、尺度变化更大，而且雾天、夜间等退化环境会进一步破坏目标纹理和对比度，导致传统单一检测器的表征能力不足。  
基于这个问题，我在 UAVDETR 的基础上，把 Decoder 中的 FFN 重构为动态 MoE 层，设置了雾天、夜间、小目标和通用四类专家，通过门控网络根据 query 特征进行动态路由。同时，我引入了 CLIP 的全局视觉语义信息辅助路由决策，让模型不只依赖局部 query，还能感知整张图的场景条件。  
此外，我还设计了路由监督和专家负载均衡机制，缓解专家塌缩和路由不稳定问题。最终在 VisDrone 上，相比 baseline，mAP 从 31.5 提升到 34.6，在复杂场景子集上的提升更明显，说明方法对极端环境和尺度变化有更好的适应能力。

```
import os
import csv
from dataclasses import dataclass
from typing import List, Tuple

import torch
import torch.nn.functional as F
from torch import nn
from torch.utils.data import Dataset, DataLoader
from PIL import Image
import open_clip


@dataclass
class TrainConfig:
    train_csv: str = "train.csv"
    val_csv: str = "val.csv"
    model_name: str = "ViT-B-32"
    pretrained: str = "openai"   # 也可以换成 open_clip.list_pretrained() 里对应的 tag
    batch_size: int = 32
    num_workers: int = 4
    epochs: int = 8
    lr: float = 1e-5
    weight_decay: float = 0.1
    warmup_steps: int = 1000
    max_grad_norm: float = 1.0
    device: str = "cuda" if torch.cuda.is_available() else "cpu"
    save_dir: str = "./checkpoints"
    use_amp: bool = True


class ImageTextCSVDataset(Dataset):
    """
    CSV 格式:
    filepath,title
    /path/to/xxx.jpg,"a UAV image captured at night"
    """
    def __init__(self, csv_path: str, image_transform, tokenizer):
        self.samples: List[Tuple[str, str]] = []
        self.image_transform = image_transform
        self.tokenizer = tokenizer

        with open(csv_path, "r", encoding="utf-8") as f:
            reader = csv.DictReader(f)
            for row in reader:
                img_path = row["filepath"]
                caption = row["title"]
                self.samples.append((img_path, caption))

    def __len__(self):
        return len(self.samples)

    def __getitem__(self, idx):
        img_path, caption = self.samples[idx]

        image = Image.open(img_path).convert("RGB")
        image = self.image_transform(image)

        # tokenizer 返回张量 shape: [1, context_length]
        text = self.tokenizer([caption])[0]

        return image, text


def clip_contrastive_loss(image_features: torch.Tensor,
                          text_features: torch.Tensor,
                          logit_scale: torch.Tensor) -> torch.Tensor:
    """
    标准 CLIP 对称对比损失:
    logits = scale * image_features @ text_features.T
    loss = (CE(logits, labels) + CE(logits.T, labels)) / 2
    """
    logits_per_image = logit_scale * image_features @ text_features.T
    logits_per_text = logits_per_image.T

    batch_size = image_features.shape[0]
    labels = torch.arange(batch_size, device=image_features.device)

    loss_i = F.cross_entropy(logits_per_image, labels)
    loss_t = F.cross_entropy(logits_per_text, labels)
    return (loss_i + loss_t) / 2.0


def build_dataloaders(cfg: TrainConfig, preprocess_train, preprocess_val, tokenizer):
    train_set = ImageTextCSVDataset(cfg.train_csv, preprocess_train, tokenizer)
    val_set = ImageTextCSVDataset(cfg.val_csv, preprocess_val, tokenizer)

    train_loader = DataLoader(
        train_set,
        batch_size=cfg.batch_size,
        shuffle=True,
        num_workers=cfg.num_workers,
        pin_memory=True,
        drop_last=True,
    )
    val_loader = DataLoader(
        val_set,
        batch_size=cfg.batch_size,
        shuffle=False,
        num_workers=cfg.num_workers,
        pin_memory=True,
        drop_last=False,
    )
    return train_loader, val_loader


def evaluate(model, val_loader, device, use_amp=True):
    model.eval()
    total_loss = 0.0
    total_count = 0

    with torch.no_grad():
        for images, texts in val_loader:
            images = images.to(device, non_blocking=True)
            texts = texts.to(device, non_blocking=True)

            autocast_enabled = use_amp and device.startswith("cuda")
            with torch.cuda.amp.autocast(enabled=autocast_enabled):
                image_features = model.encode_image(images)
                text_features = model.encode_text(texts)

                image_features = F.normalize(image_features, p=2, dim=-1)
                text_features = F.normalize(text_features, p=2, dim=-1)

                # OpenCLIP / CLIP 常见做法
                logit_scale = model.logit_scale.exp()

                loss = clip_contrastive_loss(image_features, text_features, logit_scale)

            bs = images.size(0)
            total_loss += loss.item() * bs
            total_count += bs

    return total_loss / max(total_count, 1)


def main():
    cfg = TrainConfig()
    os.makedirs(cfg.save_dir, exist_ok=True)

    # 1) 加载模型与预处理
    model, preprocess_train, preprocess_val = open_clip.create_model_and_transforms(
        cfg.model_name,
        pretrained=cfg.pretrained
    )
    tokenizer = open_clip.get_tokenizer(cfg.model_name)

    model = model.to(cfg.device)

    # 2) 数据
    train_loader, val_loader = build_dataloaders(
        cfg, preprocess_train, preprocess_val, tokenizer
    )

    # 3) 优化器
    optimizer = torch.optim.AdamW(
        model.parameters(),
        lr=cfg.lr,
        weight_decay=cfg.weight_decay
    )

    scaler = torch.cuda.amp.GradScaler(enabled=(cfg.use_amp and cfg.device.startswith("cuda")))

    # 简单 warmup + cosine
    total_steps = cfg.epochs * len(train_loader)
    def lr_lambda(step):
        if step < cfg.warmup_steps:
            return float(step) / float(max(1, cfg.warmup_steps))
        progress = float(step - cfg.warmup_steps) / float(max(1, total_steps - cfg.warmup_steps))
        return 0.5 * (1.0 + torch.cos(torch.tensor(progress * 3.1415926535))).item()

    scheduler = torch.optim.lr_scheduler.LambdaLR(optimizer, lr_lambda=lr_lambda)

    best_val = float("inf")
    global_step = 0

    for epoch in range(cfg.epochs):
        model.train()
        running_loss = 0.0
        running_count = 0

        for images, texts in train_loader:
            images = images.to(cfg.device, non_blocking=True)
            texts = texts.to(cfg.device, non_blocking=True)

            optimizer.zero_grad(set_to_none=True)

            autocast_enabled = cfg.use_amp and cfg.device.startswith("cuda")
            with torch.cuda.amp.autocast(enabled=autocast_enabled):
                image_features = model.encode_image(images)
                text_features = model.encode_text(texts)

                image_features = F.normalize(image_features, p=2, dim=-1)
                text_features = F.normalize(text_features, p=2, dim=-1)

                logit_scale = model.logit_scale.exp()
                loss = clip_contrastive_loss(image_features, text_features, logit_scale)

            scaler.scale(loss).backward()
            scaler.unscale_(optimizer)
            torch.nn.utils.clip_grad_norm_(model.parameters(), cfg.max_grad_norm)
            scaler.step(optimizer)
            scaler.update()
            scheduler.step()

            bs = images.size(0)
            running_loss += loss.item() * bs
            running_count += bs
            global_step += 1

        train_loss = running_loss / max(running_count, 1)
        val_loss = evaluate(model, val_loader, cfg.device, cfg.use_amp)

        print(
            f"Epoch [{epoch+1}/{cfg.epochs}] "
            f"train_loss={train_loss:.4f} val_loss={val_loss:.4f} "
            f"lr={optimizer.param_groups[0]['lr']:.6e}"
        )

        ckpt_path = os.path.join(cfg.save_dir, f"epoch_{epoch+1}.pt")
        torch.save(
            {
                "epoch": epoch + 1,
                "model": model.state_dict(),
                "optimizer": optimizer.state_dict(),
                "scheduler": scheduler.state_dict(),
                "config": cfg.__dict__,
            },
            ckpt_path
        )

        if val_loss < best_val:
            best_val = val_loss
            best_path = os.path.join(cfg.save_dir, "best.pt")
            torch.save(
                {
                    "epoch": epoch + 1,
                    "model": model.state_dict(),
                    "optimizer": optimizer.state_dict(),
                    "scheduler": scheduler.state_dict(),
                    "config": cfg.__dict__,
                },
                best_path
            )
            print(f"Saved best checkpoint to {best_path}")


if __name__ == "__main__":
    main()
```

### qwen微调

是不是过于简单：
第一，你是不是只是在“调用开源仓库”。  
如果只是把 Qwen2.5-VL 拉下来、改几个参数、训练一下，那含金量会被打折。  
但你这里其实不止这些，因为你做了多数据集融合、标签体系统一、格式转换、场景描述词标准化，这些都属于比较真实的工程问题。

第二，你有没有自己的判断和取舍。  
比如为什么要用 Qwen2.5-VL，而不是传统分类模型？  
为什么 LoRA 设成某个 rank？  
为什么场景感知能帮助下游检测？  
雾天和夜间数据分布差异怎么处理？  
这些问题你答得出来，项目立刻就“站住了”。

第三，你有没有闭环结果。  
你这个项目最值钱的地方，其实不是“做了一个自动标注系统”，而是它真的带来了结果：  
场景分类准确率到 92.3%，并且带动下游检测 mAP 提升 2.1%~2.2%。  
这说明它不是一个孤立 demo，而是对业务链路有价值。

#### 评价体系流程：
你的项目至少有两个输出：

1. **场景分类结果**  
    比如：晴天 / 雾天 / 夜间 / 阴天，或者更细一些的天气与场景标签。
2. **给下游检测模型的增益**

**场景分类评估 + 下游检测增益评估**

gap和抽帧的原因：

gap：如果是train和tes连续的话，就会导致test的前几帧和train的后几帧会非常像，导致测试集不是真正未知的数据，会让测试结果偏高


抽帧：只看训练集的内部，数据会高度重复导致：1、样本冗余过多，有许多相同的无用图片，即训练的成本增加而收益很小，抽帧就是为了减少训练集内部的重复样本
也可能会让模型记住运动轨迹或者背景

最基础的是：

- **Accuracy**
- **Macro-F1**

所以最好加 **Macro-F1**，这样能体现少数类比如雾天、夜间的识别能力。

## 三、第二部分：下游检测增益怎么评

这才是“应用效果”的关键。  
不然你只是证明“分类准了”，还没证明“对检测有用”。

这里最标准的做法是做**对照实验**。

### 方案设计

你至少做两组：

**Baseline：**  
只用原始图像训练检测模型，不加场景信息。

**Ours：**  
把 Qwen2.5-VL 产出的场景标签或自动标注结果引入检测训练流程。

这个“引入”可以有几种方式：

#### 方式 A：把场景标签作为数据筛选或分组依据

比如：

- 针对雾天/夜间样本做单独重采样
- 对复杂天气样本提高采样权重
- 分场景训练或分场景调参

#### 方式 B：把场景标签作为模型输入先验

例如：

- 给检测模型增加场景 embedding
- 按场景切换专家分支
- 在 prompt 或 condition 中加入 scene token

#### 方式 C：用自动标注结果扩充训练数据

例如：

- 用 Qwen2.5-VL 补全缺失场景标签
- 生成统一描述，辅助清洗和对齐训练数据
- 生成伪标签，增强特定天气场景样本

你项目里最稳妥的说法通常是 A 或 C，因为最容易落地，也最容易讲清楚。

## 四、下游检测具体怎么做评估

### 1）固定检测模型和训练设置

要保证公平比较：

- 同一个检测模型，比如 YOLO / DETR / UAV-DETR
- 同一份 train/val/test 划分
- 同样的 epoch、batch size、学习率
- 同样的随机种子，或者多次跑取平均

不然面试官会问：  
“你这个提升到底是场景模块带来的，还是训练配置变了带来的？”

### 2）看哪些指标

最常用的是：

- **mAP**
- **mAP50 / mAP50-95**
- **按场景划分的子集 mAP**
- **按目标尺度划分的小目标 mAP**

因为你项目强调的是雾天、夜间，所以最关键的是：

- overall mAP
- fog/night subset mAP

你简历里那句“雾天与夜间子集 mAP 提升 4.2，整体 mAP 提升 3.1”，本质上就是这里来的。

### 3）实验表格长什么样

你最后最好有一个类似这样的表：

|方法|Overall mAP|Fog/Night mAP|
|---|---|---|
|Baseline detector|31.8|27.4|
|+ scene labels / auto annotation|34.9|31.6|

这样你就能很自然地说：

> 构建场景分类与下游检测增益评估流程，验证场景感知模块对复杂天气检测性能的实际收益。

## 五、最好再加一个消融实验

如果你想让这句话更像真正做过实验的人写的，最好加一层 **ablation**：

- 只做数据清洗，不加场景标签
- 加场景标签，但不做 LoRA 微调
- 完整方案：数据清洗 + 场景标签 + LoRA 微调

这样你能回答一个关键问题：

**提升到底来自哪里？**

例如：

|设置|Accuracy|Overall mAP|Fog/Night mAP|
|---|---|---|---|

## 六、如果你问的是“工程上怎么写出来”

那你可以按下面这个流程实施：

### Step 1：构建测试集

单独留一份场景标注完整的 test set，包含：

- 正常天气
- 雾天
- 夜间

### Step 2：跑场景分类评估

对 test set 做推理，统计：

- accuracy
- macro-f1
- confusion matrix

### Step 3：生成场景标签/自动标注结果

把 Qwen2.5-VL 的输出整理成结构化字段，比如：

{  
  "image": "xxx.jpg",  
  "scene": "foggy",  
  "objects": ["car", "bus", "pedestrian"]  
}

### Step 4：接入检测训练流程

把 `scene` 字段用于：

- 数据分层采样
- 样本加权
- 条件输入
- 数据清洗与筛选

### Step 5：训练检测模型

分别训练：

- baseline detector
- scene-enhanced detector

### Step 6：统计检测指标

输出：

- overall mAP
- fog/night subset mAP
- small-object mAP

### Step 7：做误差分析

比如：

- 雾天误检下降多少
- 夜间漏检下降多少
- 哪类目标受益最大

这样你的“评估流程”就完整了。
